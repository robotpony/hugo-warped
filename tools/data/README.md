# Tool data

- `common-en.txt`: the 25,000 most common English words, most common first, one per line. `glossary.py candidates` treats any word not in it as rare. It's from [wordfreq](https://github.com/rspeer/wordfreq) by Robyn Speer, by way of Allison Parrish's [wordfreq-en-25000](https://github.com/aparrish/wordfreq-en-25000), with the frequencies dropped.
